# Fixes and extra patterns

Two things `../../linkedin/references/voice.md` does not hold: how to fix each kind of tell without trading
it for another, and patterns it does not list. The tell list itself lives in voice.md only.

## Fixing without a new tell

| Tell (voice.md) | Fix | Trap to avoid |
|---|---|---|
| Tell word | the plain word, or cut the word | a synonym from the same list ("leverage" to "harness") |
| Negative parallelism | state Y alone | "Y. Not X." at the end, the same move reversed |
| Triplet by reflex | keep the item that matters; two is fine | a pair of perfectly parallel clauses, the same rhythm in two |
| Reveal set-up | say the thing where the set-up was | a colon or question that still stages it |
| Pointer phrase | name the thing the phrase points at; ask the user if you do not know it | a different pointer ("the key thing is") |
| Sincerity flag | delete it; the sentence after it carries the weight | moving the flag later in the text |
| Staccato | merge the fragments into one sentence that says why | swapping for three short sentences of equal length |
| "-ing" tail | cut the tail, or make it its own sentence with a subject | a "which" clause saying the same vague thing |
| Vague authority | name the source the user gave, or drop the claim | inventing a source |
| "Serves as", "stands as" | "is" | |
| Hedge tail, self-downplay | cut it | cutting the one line in a DM that leaves them free to say no (conversations.md) |
| Assistant voice | cut the line | |
| Engagement bait | a real question about the topic, or a flat stop | "What do you think?", bait in softer words |
| Praise filler | the specific thing that was good, said as a reaction, or cut | a longer compliment |
| Bold, emoji bullets, inline headers | plain sentences or a plain numbered list | |

After fixing, read the whole text once more: fixes cluster, and three clean fixes in one paragraph can leave
it reading flat. If they do, rewrite that paragraph from its point.

## Patterns voice.md does not list

Treat these like tell-list entries (rule 3 of the check).

- **Throat-clearing opener**: "I want to share", "I've been thinking a lot about", "In today's world", "Let's
  talk about". Start at the sentence after it (P9).
- **Signposting**: "Let's dive in", "Let's break it down", "Here's how", "Buckle up", "A thread". Cut.
- **Summary closer**: "In short", "In conclusion", "Overall", "At the end of the day", "The takeaway". End
  one sentence earlier.
- **Humblebrag frame**: "humbled to", "honored to announce", "excited to share that". State the news (P4).
- **Stacked abstract nouns**: "the optimization of the implementation of". Use the verb (W1, W7).
- **Chat-tool leakage**: "Sure, here's a draft", "Here is a revised version", citation markers like "[1]" or
  "source:" stubs from a chat answer, a title line above a post. Cut.
- **Formatting LinkedIn shows raw**: markdown asterisks, "#" headings, "[text](url)" links, bullet
  characters pasted from a document. Plain text only.
- **Uniform paragraphs**: every paragraph the same length and built the same way (claim, example, moral).
  Vary by content: let one idea take one line and another take three.
- **Mirrored slogans**: "Build the team, and the team builds the product." Say what happened instead.
- **Outrage frame**: "Nobody is talking about", "This should scare you", "X is dead". Make the specific claim
  (P6).
